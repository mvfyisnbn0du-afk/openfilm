On macOS, an update that is ready now installs when you quit even if you open OpenFilm again right away. Opened while the update is still being installed, OpenFilm waits for the install to finish and then opens as the new version. If an install did not happen, the next launch installs it in a small window that says so, then opens as the new version. The update notice says what happens when you quit.
