The Examples and the skills show at once. OpenFilm comes with a copy of the examples index and its posters, and keeps the last index it read, so the Examples tab no longer waits on GitHub (a slow or blocked connection showed nothing); the newest index is read in the background as Studio starts. A gallery opened again shows what it read before while it asks again, skill covers and example posters stay in the browser's cache, and the app reads what the composer's skills need as it starts.
