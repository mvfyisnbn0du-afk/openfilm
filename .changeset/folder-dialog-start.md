"Change…" for where exports go no longer opens a folder dialog that closes at once: the dialog starts in the folder shown, or the nearest one above it that is there yet (the exports folder is made by the first export), and Finder is no longer asked to find that folder itself. The same for importing and linking media. The export dialog's choices are a capsule inside a capsule, an even gap all round, and the layout menu's rows round as the menu does. The export's custom frame is one more chip in the row of frames, its width and height capsules inside it.
