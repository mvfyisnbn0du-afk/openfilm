Desktop: keys and clicks in the chat stay in the chat. A click anywhere in it, not only in the message box, keeps the keyboard there: Space no longer plays the film, and Delete, ⌘A or ⌘Z no longer act on Studio. Clicking into the chat keeps what is selected in Studio, so the message can point at it. Typing while a media file is previewed no longer plays it or loses the spaces.
