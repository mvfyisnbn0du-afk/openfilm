Studio: layers inside a page can be copied and pasted, as in a design tool. Select one or more on the picture or in the Layers panel, then press ⌘C / Ctrl+C or choose Copy in the layer's menu (a Layers row now has a right-click menu with Copy, Paste and Delete). Paste with ⌘V / Ctrl+V or Paste in a menu: the copy is a new layer of the same page, on top of the layers beside it, a little lower and to the right each time, and selected so it can be moved at once. It plays as the copied layer does, shows in the Layers panel, and is drawn in exports. One undo removes it, and Delete removes it from the film. The page file is not changed: the copy is a new override field, `copy` (SPEC.md §1), `{"at": "#title", "copy": 1}`, whose copy carries `data-film-copy="1"` so later entries can name it. Pasted where that page is not under the playhead (another page, or another project), the layer arrives as a clip of its own showing that layer alone, from the moment it was copied; a page from another project is copied into `pasted/<project name>/`. A paste pastes whatever was copied last: layers, or clips on the timeline.
