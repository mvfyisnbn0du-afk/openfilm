Your own key: each model has the reasoning efforts you give it. In Settings → Agents → Your own key, models are a list: add one by name, tick the efforts it takes (Auto, Off, Minimal, Low, Medium, High, Extra high, Max) and choose the one it starts on. The chat's model menu then offers those efforts for that model, as it does for Claude Code and Codex. Auto sends no reasoning setting and lets the service decide; a new model offers Auto alone, so nothing changes until you choose.
