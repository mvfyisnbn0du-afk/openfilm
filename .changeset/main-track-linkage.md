Studio: the timeline works like CapCut's. The magnet is now the main-track magnet, on by default: the main track (the lowest picture track) stays closed up, so a clip put down there inserts, a delete or a clip dragged off it closes the gap, and trims ripple. Other tracks stay free: a clip put down there overwrites and a delete leaves a gap.
A new Linkage switch, on by default, carries titles, B-roll and sound with the main-track clip they start over when that clip moves, is deleted, trimmed or sped up. A long clip under several shots, such as a music bed, stays where it is, and a carried clip that would run into another moves to a free track. Sync lock is still there for Premiere habits, now off by default. ⌘B and Q / W with nothing selected act on the main track.
