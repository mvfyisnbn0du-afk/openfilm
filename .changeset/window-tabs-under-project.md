Studio: a window's tab is drawn under the project it is in, and every tab can open another window in its own project. The tab strip used to draw the windows where the app happened to keep them, so a window read as a tab of its own and nothing said which project it belonged to; a window is now brought out to just after the project it is in, indented and marked, the same way the Projects list says it. The tab in front already offered a new window; now every tab does, so another window can be opened in a project without bringing that project to the front first.
