Studio run with npm updates itself: when a newer OpenFilm is out, Update appears in the top bar (and in Settings → About), and a click runs the newest in the background; Studio starts again on it and the page comes back on the new version. `openfilm update` does the same from a terminal, or for an agent asked to update OpenFilm. The desktop app's Studio still updates with the app.
