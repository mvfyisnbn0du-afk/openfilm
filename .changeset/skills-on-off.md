Skills are installed, then kept on or off. Installed lists yours first, then the OpenFilm skills you installed, this project's, and your agent's own (off until you turn one on). Each has a switch: on, an agent takes it up whenever it fits; off, no agent gets it. Discover is OpenFilm's catalog: install one to use it. A skill opens as a page with its preview, what it does, a switch, Uninstall (or Move to trash for your own), and Try now, which starts a new conversation with the skill named. `openfilm skills` lists the same skills agents get. A skill named in a message is for that message only; its instructions go to the agent once per conversation, unseen in the chat.
