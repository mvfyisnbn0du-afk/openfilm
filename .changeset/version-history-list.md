Studio: Version history is now a list of versions, like Google Docs or Figma, instead of branches and commits. Save a version with an optional name; click one to restore it or make a copy of it as a new project. Restoring really goes back, and what you had is saved as a version first, so nothing is lost. A version now keeps all the project's files except media the film doesn't use, so a font or data file a page loads by a path it builds is no longer missed. After a restore the timeline's markers, the frame rate, track names and subtitles follow the version in every window, instead of the old ones coming back with the next edit. A new setting, Settings › Advanced › Auto versions (off by default), saves versions on their own: before and after an agent's turn, and when you pause for a couple of minutes.
