A Skills button in the chat's composer, between attach and assets. It lists the skills a message can name: this project's, yours and the official ones. Pick one, or type `/`, and it goes into the message as a pill; the agent gets the skill's instructions with the message. Add a skill from a GitHub link, or open your skills folder. In OpenFilm an agent keeps its maker's own skills and gets OpenFilm's, but the skills you installed in it yourself stay off until you turn each on in the same list. This works for Claude Code, Codex, OpenCode and your own key's agent; agents that can't be told say they use all of yours. The context ring is gone: when a conversation is nearly full, a line above the composer offers a new one.
