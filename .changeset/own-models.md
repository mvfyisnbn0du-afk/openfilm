Desktop: Your own key is an agent with models of your own, each set up on its own: the name the chat shows, the API format and address of its service, its own key, the model asked for there, and the reasoning efforts it takes. The chat's model menu switches between them, from one service to another, as it does for the other agents. A model on an address already set up can take that model's key. Models set up before become one each, on the service and key they had.
